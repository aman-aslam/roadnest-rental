# Security Policy

## Supported versions

Security reports are welcome for the current default branch of this repository.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues or pull requests.

Use GitHub's **Report a vulnerability** option in the repository's Security tab (private vulnerability reporting / security advisories) when available. Include a clear description, reproduction steps, and potential impact. Do not include customer data, credentials, access tokens, or other secrets.

Reports will be reviewed as soon as reasonably possible. Please allow time for investigation and a fix before sharing details publicly.
